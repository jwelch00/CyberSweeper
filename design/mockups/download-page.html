How it plays

It's Minesweeper with no edges. Push outward as far as you can before your links run out.

Three links

Hit a mine and you lose a link. The mine stays marked and you keep going. Lose all three and the run ends.

Every number counts

Your score is the sum of every number you uncover. One 3 is worth three 1s, so the dangerous ground pays best.

Never a coin flip

The board is built so there is always a cell you can prove is safe. If you're guessing, there's a move you missed.

Keep the signal up

Signal drains while you think and refills as you reveal. Mines pack tighter the farther you get from the start.

Rivals to beat

Three bots ship on your leaderboard. Each one played 100 seeded runs; these are their best. Beat them to unlock palettes.

Install

Download, unzip, play. The builds aren't code-signed yet, so your OS will ask once.

Windows Your system

Windows 10 or 11, 64-bit
  1. Unzip CyberSweeper-windows.zip anywhere.
  2. Run CyberSweeper.exe.
  3. If SmartScreen appears, choose More info, then Run anyway.
Download for Windows

macOS

macOS 11 or later, Apple silicon and Intel
  1. Unzip and drag CyberSweeper into Applications.
  2. Open it once. When macOS blocks it, go to System Settings, Privacy & Security, and choose Open Anyway.
Download for macOS

Linux

x86_64, any modern distro
  1. Extract with tar xzf CyberSweeper-linux.tar.gz.
  2. Run ./CyberSweeper.x86_64.
  3. If it won't launch, run chmod +x CyberSweeper.x86_64 first.
