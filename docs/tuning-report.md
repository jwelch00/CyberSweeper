## Bots

How the bots play: each one keeps its own solver, limited to its tier, fed only what a player can see. Each move it thinks (seeded log-normal time, more for harder deductions), then clicks. A cell it had already worked out right next to its last click is a quick follow-up click, the way people clear a solved patch. It only looks for safe cells within *attention* cells of its last click; with none in view it guesses locally (*local guess*) or searches the board, which costs extra time. *Misclick* sends the click to a random hidden neighbour. Runner and Netrunner flag and chord when that opens 3+ cells. NULL//SAINT never acts faster than 500 ms. `reference` is not a rival: it stands in for a decent human and sets the run-length target.

## Proposed rival scores

Each rival's score is its bot's median run, rounded to 10. The last column is how often a reference (decent human) run beats it. ## Proposed unlock thresholds

- **Root access:** decrypt 25,000 tiles across all runs (about ten typical runs; reference median is 2,520 tiles per run).
- **Rustbelt:** reach depth 120 in one run (a reference run gets there about 9% of the time; median depth 87).
- **Hotwire** and **Icebreaker** stay tied to beating mx_halcyon and NULL//SAINT.
