How it plays

It's Minesweeper with no edges. Push outward as far as you can before your links run out. Or pick Ghost mode: no signal, no clock, and you end the run when you like.

Three links

Hit a mine and you lose a link. The mine stays marked and you keep going. Lose all three and the run ends.

Every number counts

Your score is the sum of every number you uncover. One 3 is worth three 1s, so the dangerous ground pays best.

Never a coin flip

The board is built so there is always a cell you can prove is safe. If you're guessing, there's a move you missed.

Keep the signal up

Signal drains while you think and refills as you reveal. Mines pack tighter the farther you get from the start.

Rivals to beat

Seven rivals ship on your leaderboard, from lil.byte, whom anyone can beat, up to NULL//SAINT. Each score is that rival's typical run over 300 seeded games. Beat them to unlock palettes.

Install

Download, unzip, play. The builds aren't code-signed yet, so your OS will ask once.

Windows Your system

Windows 10 or 11, 64-bit
  1. Unzip {{WINDOWS_FILE}} anywhere.
  2. Run CyberSweeper.exe in the CyberSweeper folder.
  3. If SmartScreen says it protected your PC, choose More info, then Run anyway.
